# Котельная — публичный дубль (только чтение)

Статический дубль приложения «Котельная», поднятый на **GitHub Pages**:
https://gibertlega.github.io/teplo-site/

Это **не боевой вариант**. Рабочее приложение: https://legagibert.ru/teplo/

## Что здесь есть
- Фронтенд из приватного репо `gibertlega/teplo-app` (`frontend/`).
- Снимок `data.json` на момент публикации (данные НЕ обновляются автоматически).
- Кнопки «Обновить» и «Сохранить» отключены — дубль только показывает данные.

## Зачем
Безопасный дубль по Фазе 2 плана переноса: бесплатный хостинг, красивый URL,
доступный без VPN. Боевой сервер (`hermes-teplo`, `/var/www/html/teplo`) не тронут.

## Обновление
Источник истины — приватный репо `gibertlega/teplo-app`. Схема деплоя и чек-лист — в приватном репо `teplo-app`, файл `docs/DEPLOY.md`.
Вручную: скопировать `frontend/*` и свежий `data.json` в этот репо и запушить в `main`.
